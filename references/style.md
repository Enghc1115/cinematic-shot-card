# 风格参考速查

从想要的画面质感倒推参考。选好后在镜头卡末尾写一行，例如「【风格参考】ARRI ALEXA 的温润肤色与柔和高光」。光源清单和缺陷清单负责写清具体效果，器材名称用来提示质感方向。保留镜头卡已有的布光、成像效果、焦距和画幅。

## 摄影机与胶片

| 参考 | 可借用的画面质感 | 常用场景 |
| --- | --- | --- |
| ARRI ALEXA | 温润肤色，柔和的高光过渡 | 人物、剧情、对话 |
| RED | 锐利、细节丰富、偏冷硬的观感 | 动作、科幻、广告 |
| Sony VENICE | 干净的暗部、克制的噪点、自然的色彩 | 夜景、低光、室内 |
| IMAX 70mm | 清晰的大画幅胶片观感，强调空间纵深 | 大外景、巨物、航拍 |
| Kodak Vision3 500T（35mm 胶片） | 暖调、细颗粒、灯光边缘轻微光晕 | 夜景、都市、怀旧 |
| 16mm / Super 8 | 粗颗粒、暗角、轻微闪烁 | 回忆、纪录、MV |
