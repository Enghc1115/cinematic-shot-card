# 电影感镜头卡

一个 Codex Skill，用来把零散的画面描述或已有提示词整理成一张可复制的中文镜头卡，适用于单镜头剧照和单镜头视频。

## 知识来源

镜头卡结构、五类成像缺陷、缺陷速查和风格参考来自 Cara_Mosquito 老师。本项目将这些资料整理为可在 Codex 中调用的 Skill。 [Cara_Mosquito 的 X 主页](https://x.com/Cara_Mosquito)

## 这个 Skill 为什么存在

**有些 AI 画面的假感，恰恰来自它太完美。** CG 镜头即使模型、材质和灯光都做对了，也可能因为表面太光滑、高光边缘太利落、远近同样清楚，看起来缺少实拍的质感。合成师会根据镜头补入细微的颗粒、溢光、色散或失焦，让画面更像经过摄影机成像。

「8K」「超写实」「电影感」给的是宽泛方向。镜头卡把这些方向落到画面里，例如「窗外两个红点失焦成柔软光斑」或「暗部只留一点细颗粒」。**先定光，再写成像细节。**

## 合成师的五类缺陷

| 类别 | 在画面里可以看见什么 |
| --- | --- |
| 光 | 强光边缘轻微溢出。需要胶片光晕（Halation）时，高光周围带细微的红橙色晕边。 |
| 镜头 | 眩光、暗角、边缘畸变或色散。焦外光斑还可以有圆形、椭圆等具体形状。 |
| 介质 | 胶片颗粒或数字机暗部噪点。细微纹理可以给过于平滑的画面增加质感。 |
| 焦点 | 清晰范围有前后层次。浅景深时，焦平面附近清晰，其他部分逐渐虚化。视频跟焦时，焦点也可以有一点追赶。 |
| 空气 | 有空气透视时，远景的对比和饱和度降低，有时偏灰或偏蓝，远近和尺度更容易读出来。 |

## 镜头卡结构和模板

1. **人物锁定**交代谁在画面里、穿什么、有哪些关键特征。集中写一次，后面沿用角色称呼，便于保持人物连续性。空镜可以省略这一栏。
2. **光源清单**写每个光源的位置、颜色、软硬和照亮范围，并列出画面可见的路灯、屏幕或指示灯等点光源。
3. **缺陷清单**通常从五类里选 2–3 类，写清效果出现在哪里、是什么形状、强度有多大。按场景条件和创作者的选择填写。
4. **调度与表演**写景别、焦距、机位和动作。视频按需补镜头运动、动作顺序和台词。
5. **风格参考**可选，一行就够。可以写「ARRI ALEXA 的温润肤色与柔和高光」或「Kodak Vision3 500T 胶片质感」。器材名提供方向，布光和缺陷清单描述具体的画面效果。

光源放在缺陷前面，是为了给效果一个可见的依据。比如车灯的强光射进镜头时，可以考虑眩光。远处指示灯处于焦外时，可以描述它化成怎样的光斑。

```text
【人物锁定】
[角色]：[服装、发型、关键特征]。以下画面中服装保持不变。

【光源清单】
[时间、地点]。
主光：[方向、颜色、软硬、照亮范围]。
点光源：[画面里可见的灯或其他点光源]。

【缺陷清单】
[类别]：[具体效果和出现位置]。

【调度与表演】
[景别、焦距、机位、运动]。[动作]。[台词]。

【风格参考】[可选的摄影机、镜头或胶片质感]
```

## 缺陷速查

布光还没定时，可以从想要的效果倒推需要的光源或拍摄条件。布光已经定好时，就用现有光源、景深和环境筛选候选，由创作者挑选。 [完整缺陷速查](references/imperfections.md)

| 想要的效果 | 光源或拍摄条件 | 提示词写法 |
| --- | --- | --- |
| 胶片光晕 | 霓虹、警示灯或路灯形成明亮高光 | 高光边缘泛出一圈细微的红橙色光晕。 |
| 镜头眩光 | 车灯、探照灯或太阳的强光射进镜头 | 强光附近有轻微的横向眩光和光斑。 |
| 焦外光斑 | 背景小灯点或指示灯处于焦外 | 主体清晰，远处的小灯点虚化成柔软光斑。 |
| 轮廓光 | 低角度逆光擦过头发或肩线 | 暖色逆光勾出头发边缘。写入光源清单，颜色跟随光源。 |
| 巨物的尺度感 | 白天外景有足够视距，远处有空气透视、雾或扬尘 | 巨物越远的部分越淡、越偏灰蓝。场景有扬尘时，写清遮住的范围。 |

## 使用方法

在 Codex 里输入 `$cinematic-shot-card`，接着用自己的话描述想要的画面。下面这段可以直接试用。

```text
用 $cinematic-shot-card 写一张剧照镜头卡。阴天下午，一位穿米色针织衫的女性坐在窗边。
左侧窗户的柔光是唯一光源。50mm，平视，中近景，背景轻微虚化。
肤色温润、高光柔和，帮我挑一条摄影机质感参考。
```

- **缺陷已定**时，Skill 会把你给出的效果归入对应类别，直接出卡。
- **缺陷拿不准**时，Skill 会根据现有布光、景深和环境给出候选，等你选定再出卡。
- **需要风格参考**时，可以指定摄影机、胶片或镜头，也可以描述想要的质感，让 Skill 挑一条写在最后。

## 在另一台电脑上使用

把仓库完整复制到 Codex 的个人 Skills 目录，文件夹命名为 `cinematic-shot-card`。以下命令适用于默认目录。

```sh
git clone https://github.com/Enghc1115/cinematic-shot-card.git ~/.codex/skills/cinematic-shot-card
```

复制完成后，在 Codex 新对话中输入 `$cinematic-shot-card` 即可调用。

## AI 负责干净，你负责「脏」

这一步留给对质感要求较高、而且生成结果偏差明显的镜头。如果用镜头卡生成的画面里，颗粒、光晕等效果离预期太远，可以先生成一版干净的画面，把这些成像细节留到后期。

做视频时，先用镜头卡定好首帧的构图和布光。后期按需要处理这些细节。

- **颗粒**随帧变化，避免纹理像贴在画面上。
- **光晕**从最亮的部分提取，染成红橙色，轻微模糊后叠回画面。
- **暗角和色散**只在画面需要时加少量。

可以用熟悉的后期工具处理，例如剪映、DaVinci Resolve（达芬奇）、After Effects 或 Nuke。
